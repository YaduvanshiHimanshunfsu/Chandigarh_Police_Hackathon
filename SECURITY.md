## Reporting a Vulnerability

We take the security and forensic integrity of **PratiBimb Praman** seriously.

If you discover a security vulnerability or a way to forge cryptographic chain-of-custody ledgers:
1. **Do NOT publicly disclose the issue** in open GitHub issues.
2. Email a detailed report to the maintainers at `security@pratibimb-praman.gov.in` (or via private security advisory on GitHub).
3. Include:
   - Type of vulnerability (e.g., hash collision, injection, authentication bypass)
   - Step-by-step reproduction instructions or proof-of-concept
   - Impact assessment on court evidence admissibility

We will acknowledge receipt within 48 hours and work with you on a responsible disclosure timeline.
